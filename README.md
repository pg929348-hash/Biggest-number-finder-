# Biggest-number-finder-
> *👑 WHO IS THE KING? 👑*

*🎯 What This Logic Does?*
We have 3 players: A, B, C. This logic finds who is the strongest / biggest among them! 💪

*🤔 How It Decides?*

1.  🥇 *Check Player A:*
    Is A bigger than both B and C? 
    If YES -> A is the KING! 👑 -> We choose A!

2.  🥈 *Check Player B:*
    If A is not the king, is B bigger than both A and C?
    If YES -> B is the KING! 👑 -> We choose B!

3.  🥉 *Check Player C:*
    If A & B both failed, is C bigger than both A and B?
    If YES -> C is the KING! 👑 -> We choose C!

4.  🤷‍♀️ *If No One Is Clearly Biggest:*
    What if two players have the same score? Or all are equal?
    Then there is NO single king! 🙅‍♂️
    So we say -> "none" 😅

*✨ Simple Example:*
Think of 3 friends with chocolates 🍫
-3, 6, 0

Who has the most? 6 has the most! So 6 wins! 🎉
